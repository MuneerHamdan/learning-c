### compiling and linking
- __preprocessor__:
    * preprocessor program looks for lines beginning with '#'
    * these lines are __directives__
    * modifies .c file based on directives
* __compiler__:
    + translates modified into machine code
    + cc, gcc, etc
+ __linker__:
    + combines machine code with additional required code
    + additional code can be library functions like printf()
+ preprocessor usually integrated with compiler
